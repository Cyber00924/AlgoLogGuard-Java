HOW IT WORKS

One event. Two layers of trust.

01
Capture

Backend receives a security event from your application or monitoring agent.

→
02
Fingerprint

SHA-256 creates a tamper-evident digest from canonical event fields.

→
03
Anchor

In live mode, the digest is placed in an Algorand TestNet transaction note. Demo mode simulates this step and clearly marks it as unanchored.

→
04
Verify

Recompute the digest and compare it with the indexed transaction note.
